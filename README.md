# SlimByte — Free Image Optimizer

![SlimByte preview](pixlite-browser-mockup.png)

🔗 **Live:** https://nuvishh.github.io/SlimByte/

Compress and resize images **right in your browser**. No upload, no signup — your photos never leave your device.

## Features

- **Drag & drop** multiple images (JPG, PNG, WebP)
- **Quality slider** (10–100%)
- **Max width** resize (keeps aspect ratio)
- **Format conversion** — JPEG / PNG / WebP
- **Before → after** sizes with % saved
- **Download** individually or all at once
- **100% client-side** — Canvas API, zero servers

## Tech

Single `index.html`. No dependencies, no build step.

## Host it

Any static host — GitHub Pages, Netlify, Vercel — or just open `index.html` locally.
